What it does

Desktop audio (Linux)

The app loads a hidden Peek Remote Audio source on the default sink's monitor — real desktop mix, nothing else, zero config. Falls back to video-only with a chip if it can't.

Full screen share

Screen video to a friend's machine or browser over a direct WebRTC connection — watch and listen first.

Keyboard + mouse control

Connect = watch & listen only. Your friend hits Take control once you click Allow control; they hand it back with the button or Ctrl+Alt+Q — Cappy jingle included. Injected locally via uinput on Linux.

Consent-gated, always

Nothing reaches your machine until you click Allow control. Enforced in Rust, not in the page — a page bug cannot bypass it. Ctrl+Alt+Q cuts it instantly on Windows.

No accounts, no server changes

Same free mailbox as Peek — same 6-character codes. Control travels inside the WebRTC data channel. The signaling server never sees a thing.

Self-contained

All libraries bundled inside the AppImage. Drop it in ~/Applications, chmod +x, done — works on the Steam Deck's read-only OS.

Actually peer-to-peer

Video and input both flow directly between the two machines. Nothing is stored, no accounts, no middle tier.

Status

Honest beta

v0.2.0 builds clean on Linux and Windows, but it has never been run end-to-end. Screen capture through WebKitGTK on Wayland — and mic capture of the hidden Peek Remote Audio source — are the known risky bits. Treat the keyboard/mouse path with the same respect you'd give a loaded gun until it's proven.

Running it (Steam Deck & other Linux)

  1. Drop peek-remote.AppImage in ~/Applications (USB, scp, rsync — anything).
  2. chmod +x ~/Applications/peek-remote.AppImage and double-click (Desktop Mode), or run it from Konsole.
  3. Deck complaint about FUSE? APPIMAGE_EXTRACT_AND_RUN=1 ~/Applications/peek-remote.AppImage
  4. For input injection, uinput needs permission: sudo usermod -a -G uinput $USER, or a one-time 60-uinput.rules via steamos-readonly disable then enable. The share/UI half needs nothing.
  5. Gaming Mode won't work — gamescope has no capture portal. Desktop Mode only.
